### 🔨 Featured Projects

**[Parista](https://github.com/Dibyajyoti1515/parista)** — Multi-agent AI system for interpersonal conflict resolution, grounded in psychological research. Six-agent pipeline (safety check → classification → retrieval → reasoning → citation verification → style calibration) built with FastAPI, Google ADK, Supabase (pgvector), and Gemini. Designed to fail closed on unverifiable citations. Built for *Deploy or Die: HowToAlgo x GDG on Campus KIIT*.

**[framein-goa](https://github.com/Dibyajyoti1515/framein-goa)** — Next.js 15 hackathon photo framing tool with branded frames, ID cards, and banner generation. TypeScript, App Router, modular component architecture.

Node.js, Express, TypeScript, MongoDB, Supabase, Firebase Admin. JWT httpOnly auth, phone OTP, QR-coded product IDs, role-based access control.
